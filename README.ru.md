# Wallet Service - Merezh

Микросервис, отвечающий за управление кошельками и балансами пользователей.

## 📋 Обзор

Wallet Service - это микросервис на Spring Boot, который управляет кошельками пользователей: создание, получение баланса, пополнение, списание и удаление. Используется Payment Service для списания средств при обработке заказов.

Сервис хранит только балансы - он **не обрабатывает платежи сам**. Payment Service вызывает Wallet Service для списания средств. Сервис доверяет заголовку `X-User-Id` от Gateway и использует пессимистичные блокировки для защиты от гонок при операциях с балансом.

## ✨ Возможности

### 👛 Управление кошельками

- Создание кошелька для пользователя (или автоматическое создание при первой операции)
- Получение текущего баланса
- Пополнение баланса
- Списание средств с проверкой достаточности
- Удаление кошелька

### 🔒 Безопасность при конкурентных операциях

- **Пессимистичная блокировка** (`@Lock(PESSIMISTIC_WRITE)`) на операциях с балансом
- Защита от двойного списания при параллельных запросах
- Атомарное обновление баланса в рамках одной транзакции

### ✅ Валидация данных

- Единый формат ошибок через `@RestControllerAdvice`
- Проверка достаточности средств перед списанием

## 📚 Эндпоинты API

Базовый путь: `/api/v1/wallets`

| Метод  | Эндпоинт          | Описание                                  | Доступ             |
|--------|-------------------|-------------------------------------------|--------------------|
| POST   | `/create`         | Создать кошелёк для аутентифицированного юзера | Authenticated  |
| GET    | `/balance`        | Получить текущий баланс пользователя      | Authenticated      |
| POST   | `/balance/sum`    | Пополнить баланс                          | Authenticated      |
| POST   | `/balance/sub`    | Списать средства                          | Authenticated / Payment Service |
| DELETE | `/delete/{id}`    | Удалить кошелёк по ID пользователя        | ADMIN              |

**Примечание:** Сервис доверяет заголовку `X-User-Id`, который устанавливает Gateway.

## 🔒 Безопасность

- **Создание кошелька инициируется аутентифицированным пользователем** (`X-User-Id` от Gateway).
- **Операции с балансом используют пессимистичную блокировку** для защиты от гонок.
- **Недостаток средств** вызывает исключение до любого изменения.
- **Сервис доверяет Gateway** в вопросе идентификации пользователя.
- **Внутренние эндпоинты** не должны публиковаться напрямую - только через Gateway.

## 🩺 Health Checks

Сервис предоставляет эндпоинты Spring Boot Actuator:

| Эндпоинт                       | Назначение                   |
|--------------------------------|------------------------------|
| `/actuator/health`             | Общий статус                 |
| `/actuator/health/liveness`    | Liveness probe               |
| `/actuator/health/readiness`   | Readiness probe (включая БД) |
| `/actuator/info`               | Информация о сервисе         |

## 🧪 Тестирование

```bash
mvn test
```

Unit-тесты покрывают основные сценарии `WalletService`:

- `sumWallet` с валидными данными → новый баланс
- `subWallet` при недостатке средств → исключение
- `subWallet` с валидными данными → новый баланс
